# 디지몬 RPG 길잡이 · 제작자 선댕

배포용 프로그램의 소스 및 자동 업데이트 저장소입니다. 전체용 자료는 포함하지 않습니다.

## 수정하는 방법
- 지도: `app/assets/`에 기존 이름과 같은 이미지 파일을 올려 교체합니다.
- 워터 경로/날짜: `app/water-guide.js`.
- 던전 조건/공략/배치: 현재 `app/index.html`에 들어 있습니다. 같은 이름의 JSON 파일은 보관 자료이므로 JSON만 수정해도 화면이 바뀌는 구조는 아직 아닙니다.
- 특성·오버라이트: `app/index.html`의 해당 데이터 및 렌더 함수를 수정합니다.
- 화면 변경을 저장하면 Actions가 배포용 EXE를 빌드하고 Releases에 올립니다.
- 빌드 성공 후에만 `updates/public.json`이 바뀝니다. 이미 받은 자동 업데이트 지원 버전은 다음 실행 시 이를 확인합니다.

## 처음 받는 사람
오른쪽 Releases에서 최신 `Seondaeng_Digimon.exe`를 한 번 받아 실행하세요.
기존 1.2에는 자동 업데이트 코드가 없어서 최초 1회 새 파일을 직접 받아야 합니다.
프로그램 홈의 `업데이트 확인` 버튼으로도 확인할 수 있습니다.

## 자동 업데이트
실행 시, 실행 중 1시간마다, 수동 확인 시 새 버전을 확인합니다.
다운로드 크기와 SHA-256을 확인한 뒤 프로그램을 종료하고 원래 EXE를 교체한 후 다시 실행합니다.
통신/검증 실패 시 기존 버전을 유지합니다. 교체 전 파일은 `.previous`로 남습니다.
GitHub 비밀번호나 토큰을 배포 파일에 넣지 않습니다.

## 이미지 보관
첫 빌드에는 기존 공개 홈페이지에서 이미지 파일을 가져와 해시를 확인합니다.
성공 후 `bootstrap-assets` 릴리스의 `assets.zip`으로 보관해 다음 빌드부터 GitHub 자료를 사용합니다.
저장소 `app/assets/`에 직접 올린 파일이 우선합니다.

## 확인이 필요한 사항
Linux에서 네이티브 Windows 대상으로 컴파일 및 스크립트 구문 검사를 했습니다.
실제 Windows에서 다운로드 → 종료 → 교체 → 재실행 동작은 최종 시험이 필요합니다.
이 저장소는 GitHub에 저장하는 순간 바로 실행 화면을 바꾸는 콘텐츠 동기화가 아니라,
변경 후 새 EXE를 자동으로 만들어 배포하고 프로그램이 이를 받는 구조입니다.
